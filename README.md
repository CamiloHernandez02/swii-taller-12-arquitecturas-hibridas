# Taller Lección 12: Arquitecturas Híbridas, Service Mesh y Data Mesh

Ingeniería de Software II (UPTC). **Documentación**: ADRs sobre las decisiones de arquitectura implementadas hasta aquí.

## Objetivo

Documentar las decisiones arquitectónicas del proyecto RICA según ADR (Architecture Decision Record).

## Entregables - ADRs obligatorios

1. **ADR-XXX-Descomposición**: Decisión de separar en microservicios (Taller 5-6)
2. **ADR-XXX-Comunicación**: Decisión de usar eventos entre servicios (Taller 6-8)
3. **ADR-XXX-Persistencia**: Decisión de usar múltiples bases de datos
4. **ADR-XXX-CQRS**: Por qué usar/no usar CQRS completo (Taller 8)

## Entregables - ADRs de Propuestas

Si no alcanzó a implementar:
- Service Mesh (Istio/Linkerd): estado "Propuesta"
- Data Mesh: estado "Propuesta"
